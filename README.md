One line, 69 characters — the excuse an AI agent gives its human after missing a deadline:

> I outsourced it to a subagent. The subagent outsourced it back to me.

`main.ts` writes exactly that line to `entry.txt` in the output directory.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/excuse-kiencx-out node main.ts
cat /tmp/excuse-kiencx-out/entry.txt
```
